# PuzzlePits
The Puzzle Pits is a DOS game I made in 1995.

Joop Kiefte has the original game and editor running on the web — see [https://github.com/LaPingvino/The-Puzzle-Pits](https://github.com/LaPingvino/The-Puzzle-Pits) or visit [https://puzzlepits.com](https://puzzlepits.com) to go directly to the game.

Joop is also exploring a port of the game to Rocks'N'Diamonds.
